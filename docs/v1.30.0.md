# v1.30.0 版本说明

发布日期：2026-08-17

v1.30.0 将 AutoforgeHub 集成到 Autoforge 的原生工作流中。登录一次后，用户可以在桌面应用内浏览插件市场、个人工作区和团队工作区，并直接安装或更新脚本。

## 主要更新

### AutoforgeHub 浏览器授权登录

- 登录操作会跳转到 AutoforgeHub 页面完成，不在 Autoforge 内嵌密码表单。
- 授权请求使用 `state`、一次性授权码和 PKCE，避免回调被伪造或重复使用。
- Hub 授权完成后回调到本机 `127.0.0.1:19276/auth/callback`，Autoforge 主进程接收并保存凭据。
- 凭据只由主进程管理，渲染进程通过受限的 preload API 获取脱敏账户信息。
- 授权等待页会在成功、失败或超时后结束等待，并提供返回脚本中心的明确反馈。

### 原生脚本中心

脚本中心提供三个内容范围：

- **插件市场**：浏览 Hub 公开发布的脚本。
- **我的脚本**：查看当前账户拥有或发布的脚本。
- **团队脚本**：查看当前账户所在团队可访问的脚本。

脚本详情展示版本、作者、分类、更新时间、安装状态和 Markdown README。README 使用 `markdown-it` 解析，并通过 `DOMPurify` 清理后渲染；详情区域独立滚动，不会撑开或遮挡页面布局。

### 搜索与分类筛选

- 搜索框将关键词作为 `q` 参数发送到 Hub。
- 分类筛选使用 `category` 参数，并读取 `distributions.category` 显示分类名称和数量。
- 搜索、分类和内容范围可以组合使用，切换条件后会重置分页并保留当前登录状态。
- 空结果、加载中和请求失败均有独立状态提示，避免将“暂无结果”误判为网络错误。

### 一键安装与实时刷新

- 在脚本详情或卡片中点击“安装”即可将 Hub 脚本下载并导入本地脚本库。
- 已安装脚本显示更新入口；更新时沿用本地脚本 ID、配置、收藏和定时任务。
- 安装成功后主页面通过 `EVENT_HUB_SCRIPT_INSTALLED` 刷新脚本列表并自动选中新脚本，无需重启 Autoforge。
- 本地安装桥仅监听 `127.0.0.1:19276`，Hub 传入公开 HTTPS zip 地址和稳定的 `hubScriptId`。

### 账户设置

- 设置页新增账户模块，显示当前用户资料、登录状态和团队数量。
- 退出登录入口统一放在账户设置中，脚本中心不再显示重复的退出按钮。
- 退出登录需要二次确认；确认后清理本地 Hub 凭据并回到未登录状态。

### 交互与视觉优化

- 脚本中心标题栏新增返回按钮，可关闭当前脚本中心页面。
- 使用 Autoforge 应用图标作为标题栏品牌标识。
- 重做脚本卡片层级、状态标签、操作区和响应式间距，提升扫描效率。
- 登录页、空状态、错误状态和安装反馈统一使用 Hub/Autoforge 主题与交互语言。

## 使用流程

1. 打开 Autoforge 的“脚本中心”，点击登录。
2. 在浏览器打开的 AutoforgeHub 页面完成登录和授权。
3. 返回 Autoforge，进入“插件市场”“我的脚本”或“团队脚本”。
4. 使用搜索框和分类筛选定位脚本，打开详情查看 Markdown 说明。
5. 点击“安装”或“更新”，完成后返回主页面即可看到脚本。
6. 在“设置 > 账户”中查看账户信息或退出登录。

## 安全边界

- Autoforge 不接收或存储 Hub 密码，登录始终在系统浏览器中完成。
- 回调服务仅绑定本机回环地址，并校验授权状态、PKCE 和一次性 code。
- 访问令牌不会暴露给页面脚本；登出时同时清理主进程凭据和渲染进程缓存状态。
- Markdown 详情经过 HTML 清理，外部链接交由系统浏览器打开。
- 脚本 zip 下载、解压和导入继续遵守现有路径、条目数、下载大小和解压大小限制。
