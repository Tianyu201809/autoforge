# Autoforge v1.42.0 版本说明

发布日期：2026-11-22

v1.42.0 加固 Hub 脚本安装与本机数据保存，并将 JavaScript 脚本运行移至独立宿主进程。脚本包清单规范仍为 `autoforge` **1.0**。

## 主要更新

### Hub 安装校验

- 本机安装桥仍监听 `127.0.0.1:19276`。`POST /install` 只接受 `hubScriptId` 和一次性 `installToken`，令牌有效期为 120 秒。
- 桥校验请求 `Origin` 与设置中的 Hub 源一致，再由桌面端构造 Hub 下载地址。网页不能指定任意 `zipUrl`。
- Hub 保存脚本包 SHA-256，安装令牌响应和下载响应分别提供哈希。桌面端校验下载内容与 `X-Autoforge-Sha256`，应用内安装还会比对令牌响应中的哈希。
- 缺少哈希或校验不一致时，安装失败并删除临时下载，不会解压或导入脚本。
- 网页安装请求仅提交 Hub 脚本 ID 和安装令牌，不再提交可任意指定的下载地址。

### JavaScript 宿主进程

- 每次 JavaScript 脚本运行都使用独立的 Electron `utilityProcess`。
- 用户停止或超时先向宿主发送退出信号，并等待 1 秒。宿主仍未退出时，桌面端会终止宿主和已上报的浏览器进程。
- 用户停止记录为 `stopped`，超时记录为 `error` 并包含超时时长。
- Python 和原生可执行脚本继续使用各自的子进程运行方式。
- `utilityProcess` 提供进程隔离，但不限制脚本访问本机文件或网络。

### SQLite 原子落盘

- 普通写入在最后一次变更后 300 ms 防抖落盘，同一批连续写入最迟 1000 ms 刷盘。
- 事务提交、数据库关闭和启动迁移完成后立即落盘。
- 数据库写入同目录临时文件并 `fsync` 后替换。启动时会删除残留临时文件并继续使用原数据库。

### 环境变量加密

- 系统加密可用时，`environments.variables` 的 JSON 使用 Electron `safeStorage` 加密，数据库文本以 `enc:v1:` 和 Base64 密文保存。名称与描述仍为明文。
- 已有明文记录会在启动时迁移。无法解密的记录会标记为不可读并拒绝覆盖。
- 系统加密不可用时保留明文保存，并在设置页显示状态提示。密文依赖当前设备和用户的系统密钥。

## 兼容性

- 不改变 `autoforge.json` 的规范版本和脚本入口格式。
- 环境变量密文依赖本机用户的系统密钥，不能作为跨设备备份格式。
- Hub 安装需使用支持 SHA-256 安装契约的 AutoforgeHub 版本。
- JavaScript 子进程没有文件系统或网络权限沙箱，运行不可信脚本前仍需确认脚本来源。
