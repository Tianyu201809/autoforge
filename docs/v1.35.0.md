# Autoforge v1.35.0 版本说明

发布日期：2026-08-30

v1.35.0 聚焦插件中心的安装效率、栏目切换体验和视觉一致性。脚本包清单规范仍为 `autoforge` **1.0**，本次版本不改变脚本包格式或 Hub IPC 协议。

## 主要更新

### 插件中心并发安装

- 最多允许 5 个脚本同时安装，单个脚本的下载与导入不会阻塞其他脚本。
- 每个脚本独立维护安装阶段、下载进度和错误状态。
- 安装失败可直接在对应卡片或详情面板重试；达到并发上限时，其他安装按钮会保持禁用状态。

### 发布时间排序

插件市场、个人脚本和团队脚本统一按 `publishedAt` 倒序排列。服务端未提供发布时间时使用 `createdAt`，日期相同时按脚本名称稳定排序。

### 三栏独立缓存

插件中心为三个栏目建立独立缓存：

| 栏目 | 缓存隔离键 |
|------|------------|
| 脚本市场 | 搜索词、分类 |
| 我的脚本 | 搜索词、分类 |
| 团队脚本 | 团队 ID、搜索词、分类 |

切换侧边栏或重新打开插件中心时，优先恢复对应栏目的列表，不再使用其他栏目的结果。搜索词和分类筛选也按栏目保存；团队切换时会恢复该团队自己的筛选状态。手动点击刷新仍会绕过缓存获取最新数据。退出登录后会清理所有缓存和团队信息。

### 卡片与主题优化

- 插件卡片重新组织标题、描述、分类、作者、安装次数和发布时间，保持稳定尺寸并提升扫描效率。
- 图标区域改为灰阶徽章与主题色细节线，减少高饱和色块对内容的干扰。
- 石墨和净白主题统一使用简约黑白灰色板，调整边框、表面层级、悬停状态和控件对比度。

## 使用说明

1. 打开「脚本中心」并完成 AutoforgeHub 授权。
2. 在「脚本市场」「我的脚本」或「团队脚本」中浏览脚本。
3. 可连续点击多个安装按钮，最多同时进行 5 个安装任务。
4. 使用搜索和分类筛选后切换栏目，返回时会保留每个栏目的独立结果。
5. 需要获取最新列表时，点击当前栏目右上角的刷新按钮。

## 兼容性

- 不需要迁移本地脚本、环境或执行历史数据。
- `autoforge.json` 的规范版本仍为 `1.0`。
- 退出 Hub 账户会清理插件中心缓存，但不会删除已安装脚本。
