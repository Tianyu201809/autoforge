# Autoforge v1.26.0 版本说明

> 发布日期：2026-08-10 · 应用版本 `1.26.0` · 脚本规范 `autoforge 1.0`

Autoforge 是本机自动化脚本锻造与管理桌面应用。v1.26.0 改进脚本列表的大数据量浏览效率，并让脚本参数、环境变量等文本配置可直接接收从资源管理器拖入的本地文件路径。

完整功能基线见 [v1.9.0](./v1.9.0.md)；本地 MCP 控制面见 [v1.24.0](./v1.24.0.md)。本文档仅描述 v1.26.0 新增与变更。

设计规格：

- [脚本列表分页增强](./superpowers/specs/2026-08-10-script-list-pagination-design.md)
- [文本输入框文件路径拖入](./superpowers/specs/2026-08-10-file-path-drop-inputs-design.md)

## 相对 v1.25.0 的变化

| 领域 | 变更 |
|------|------|
| **脚本列表分页** | 支持直接点击页码，页数较多时固定首末页并显示当前页附近页码与省略号 |
| **快速跳页** | 分页栏新增页码输入与“跳转”操作，支持按 Enter 提交；空值与非整数恢复当前页，越界值自动限制在有效范围 |
| **响应式分页栏** | 分页控件采用固定尺寸并可在窄窗口自动换行，当前页通过清晰状态与 `aria-current="page"` 标记 |
| **文件路径拖入** | 可编辑文本输入框和文本框支持直接拖入本地文件或目录，自动写入绝对路径 |
| **批量路径** | 同时拖入多个文件时按拖入顺序以换行符写入，避免路径内空格产生歧义 |
| **表单兼容性** | 路径写入会派发原生 `input` 事件，已有 `v-model`、保存和脏状态逻辑无需改造 |
| **拖入边界** | 密码、数值、搜索、选择、Cron、附件、复选/单选、只读和禁用控件不会接收路径 |

## 脚本列表分页

脚本列表仍保持每页 12 条记录。分页栏除“上一页”“下一页”外，现在提供可点击页码和快速跳页：

- 页数不超过 5 页时显示所有页码；
- 页数更多时始终保留第 1 页、最后一页、当前页以及相邻页；
- 连续页码间只缺 1 页时直接显示该页，间隔更大时显示省略号；
- 输入目标页码后按 Enter 或点击“跳转”即可定位；
- 筛选、排序切换仍回到第 1 页；数据减少导致当前页失效时会自动修正到最后有效页。

例如第 5 / 10 页显示为：`1 ... 4 5 6 ... 10`。

## 文本输入框拖入路径

在支持的表单字段中，可从系统资源管理器将文件或目录拖到输入框：

1. 将一个文件或目录拖到文本输入框或多行文本框。
2. 控件边框会显示主题色高亮。
3. 放下后，绝对路径会替换当前输入值。
4. 多个文件会按拖入顺序，每行一个路径写入。

该功能只写入路径文本，不读取文件内容、不上传文件，也不会移动、复制或导入文件。脚本导入区仍保留原有的专用拖入导入行为。

支持普通文本、URL、邮箱、电话输入和多行文本框。以下控件保持原有语义，不接收路径：搜索、密码、数值、日期时间、复选框、单选框、附件字段、选择框、Cron 控件、只读和禁用控件。

## 质量验证

- 新增分页模型测试，覆盖页码窗口、省略号和跳页输入边界；
- 新增 preload 路径拖入测试，覆盖单文件、多文件、无路径和反馈清理；
- 新增 renderer 指令测试，覆盖允许的文本控件及各类排除项；
- 完整单元测试、lint 与生产构建均已通过。
