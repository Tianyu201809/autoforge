# Autoforge v1.36.0 版本说明

发布日期：2026-08-30

v1.36.0 优化脚本列表的分类筛选规则。脚本包清单规范仍为 `autoforge` **1.0**，本次版本不改变脚本包格式、数据结构或 Hub IPC 协议。

## 主要更新

### 分类筛选基于全部脚本

- 选择分类后，列表统一从全部脚本中匹配当前分类及其子分类。
- 分类筛选不再与“运行中”“收藏”“定时任务”或“已归档”条件叠加。
- 选择分类时会自动切换到全部脚本范围，并清除状态、收藏和定时任务筛选，避免筛选状态与列表结果不一致。
- 侧边栏分类树和列表筛选面板中的分类入口使用相同规则。

## 使用说明

1. 在侧边栏选择一个分类，或在列表顶部打开筛选条件并选择分类。
2. 列表会显示该分类及其子分类下的全部脚本，包括已归档脚本。
3. 如需按运行状态、收藏或定时任务筛选，请先清除分类筛选。

## 兼容性

- 不需要迁移本地脚本、环境或执行历史数据。
- `autoforge.json` 的规范版本仍为 `1.0`。
- Hub 登录、插件中心缓存和已安装脚本不受影响。
