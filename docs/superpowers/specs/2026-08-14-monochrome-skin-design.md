# 简约黑白皮肤设计

## 背景

Autoforge 当前提供三组深浅配对皮肤。用户希望新增一组简约黑白皮肤，并继续使用现有的皮肤选择、持久化和标题栏深浅切换机制。

## 目标

- 新增一组深浅配对皮肤：深色“石墨”和浅色“净白”。
- 主体界面仅使用黑、白和中性灰建立层级。
- 保留低饱和功能色，确保状态识别和代码可读性。
- 让主窗口、独立编辑器和独立日志窗口使用一致的皮肤。
- 保持现有布局、交互和组件结构不变。

## 非目标

- 不重做应用布局、排版或信息架构。
- 不改变默认皮肤。
- 不让悬浮球随皮肤变化；悬浮球当前不属于皮肤系统。
- 不引入新的主题框架或外部依赖。

## 方案比较

### A. 克制灰阶（采用）

以近黑和纸白为底，通过四至五级中性灰表达面板、卡片、输入框和边界。主体没有彩色强调、装饰性渐变或光晕，长时间使用的视觉压力较低。

### B. 绝对黑白

仅使用纯黑、纯白和硬边框。风格最鲜明，但界面层级不足，连续使用时对比过强。

### C. 编辑感黑白

使用暖灰纸张色和更明显的印刷气质。个性更强，但会改变 Autoforge 现有工具型界面的语气。

## 视觉设计

### 石墨（深色）

- 基础背景使用近黑 `#111110`。
- 面板、卡片和输入区域使用 `#181817`、`#20201f` 等中性灰分层。
- 主文字使用柔白，次级文字和边框使用递减灰阶。
- 强调色使用柔白或浅灰；强调文字反转为近黑。

### 净白（浅色）

- 基础背景使用纸白 `#f7f7f4`。
- 面板和卡片使用纯白及浅灰分层。
- 主文字使用近黑，次级文字和边框使用递增灰阶。
- 强调色使用近黑；强调文字反转为白色。

### 共同规则

- 主按钮、选中态和焦点环采用黑白反转。
- 不使用彩色品牌强调、装饰性渐变、光晕或纸张噪点。
- 阴影仅提供轻微的悬浮反馈，边框承担主要层级表达。
- 成功、警告、错误保留低饱和绿、黄、红。
- 代码关键字、字符串、数字、布尔值和函数保留低饱和功能色。
- 皮肤预览图使用抽象工作台线框，展示深浅层级，不添加装饰插画。

## 结构与组件

### 皮肤定义

在现有皮肤预设中加入 `graphite` 和 `snow`，分别映射到深色和浅色模式。二者加入深浅配对表，标题栏按钮在两者之间切换。

现有本地存储键和旧主题兼容逻辑保持不变。无效或过期的皮肤标识继续回退到现有默认皮肤。

### 样式变量

在主题样式表中为两个新皮肤完整定义现有语义变量，包括：

- 背景、面板、表面、卡片、输入框和日志区域。
- 主文字、次级文字、弱化文字和反色文字。
- 普通边框、弱边框和输入边框。
- 强调色、标题栏、标志、焦点环和滚动条。
- 编辑器、终端和语法高亮变量。

功能状态中当前使用固定颜色的部分，为新皮肤增加限定覆盖，使其低饱和化，但不影响其他皮肤。

### 皮肤选择器

深色和浅色分组各增加一张皮肤卡。网格改为响应式布局：常规设置窗口显示四列，窄窗口显示两列，避免第四张卡片单独换行。

`SkinPreviewIcon` 为“石墨”和“净白”增加对应线框预览。

### 多窗口初始化

主窗口和独立日志窗口的启动脚本加入两个新皮肤的模式映射。独立编辑器当前只读取深浅模式，本次补齐具体皮肤读取与 `data-skin` 初始化，使其与主窗口、日志窗口一致。

## 数据流

1. 用户在设置页选择“石墨”或“净白”。
2. `useTheme` 更新响应式皮肤状态，并在根元素写入 `data-theme` 和 `data-skin`。
3. 当前皮肤写入现有 `autoforge-skin` 本地存储键。
4. CSS 语义变量随根元素属性切换。
5. 新打开的主窗口、编辑器或日志窗口从本地存储读取相同皮肤。
6. 标题栏深浅按钮根据配对表在“石墨”和“净白”之间切换。

## 异常与兼容

- 存储值不是已知皮肤时，继续回退到现有深色默认“锻炉”。
- 只有旧深浅主题值时，继续映射到现有默认深色或浅色皮肤。
- 新皮肤不会改变旧皮肤的变量或视觉效果。
- CSS 不支持特定混色表达式时，基础变量仍提供可读的前景和背景对比。

## 验收与测试

- 运行现有单元测试和生产构建。
- 验证设置页能选择“石墨”和“净白”，刷新后选择仍然保留。
- 验证标题栏按钮在这两个皮肤之间成对切换。
- 验证主窗口、独立编辑器和独立日志窗口读取相同皮肤。
- 检查设置页常规宽度四列布局和窄宽度两列布局，无溢出或孤立卡片。
- 检查按钮、输入框、选中态、悬停态、焦点态和禁用态的可读性。
- 检查成功、警告、错误及代码语法高亮仍可快速区分。
- 对深浅皮肤分别进行主界面和设置页截图检查，确认无彩色主体强调、渐变、光晕和噪点。

## 完成标准

用户可以从设置页选择一组克制灰阶的深浅黑白皮肤，并在所有现有主题窗口中获得一致、持久且可读的体验；原有皮肤和默认行为不发生回归。
