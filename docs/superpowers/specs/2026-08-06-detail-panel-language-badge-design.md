# 详情面板语言徽标设计

## 目标

在脚本详情面板头部右上角展示当前脚本语言，让用户无需查看入口文件即可快速识别 JavaScript 或 Python 脚本。

## 展示规则

- JavaScript 显示 `JS`，使用现有琥珀色描边徽标样式。
- Python 显示 `Py`，使用现有天蓝色描边徽标样式。
- 徽标位于详情头部右侧操作区，在目录、批量运行、运行等按钮上方。
- 鼠标悬停时显示完整名称：`JavaScript 脚本` 或 `Python 脚本`。

## 实现方式

详情面板直接读取现有 `script.language` 字段，并复用 `scriptLanguageBadge()` 生成文案与颜色类。右侧操作区增加一层纵向布局：语言徽标靠右对齐，原有按钮保持同一行。无需新增语言推断逻辑，也不改变脚本数据结构。

详情面板宽度低于 `620px` 时，整个操作区继续按现有容器查询规则移动到标题下方；语言徽标仍靠右显示，避免挤压脚本名称、分类和版本信息。

## 边界与兼容性

- `ScriptLanguage` 目前只允许 `javascript` 和 `python`，因此不设计未知语言占位状态。
- 徽标不提供点击行为，不影响原有头部按钮和拖拽缩放。
- 保持脚本卡片与详情面板语言标识的文案和配色一致。

## 验证

- 扩展详情头部回归测试，检查语言徽标使用共享 helper、读取 `script.language`，并包含 `JS` / `Py` 规则。
- 运行定向测试、完整单测、ESLint 和生产构建。
