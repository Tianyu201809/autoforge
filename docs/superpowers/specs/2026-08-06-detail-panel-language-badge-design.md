# 详情面板语言徽标设计

## 目标

在脚本详情面板头部右上角展示当前脚本语言，让用户无需查看入口文件即可快速识别 JavaScript 或 Python 脚本。

## 展示规则

- JavaScript 显示 `JS`，使用琥珀色浅色半透明背景、同色边框和文字。
- Python 显示 `Py`，使用天蓝色浅色半透明背景、同色边框和文字。
- 语言卡尺寸固定为 `96×52px`，位于详情头部右侧操作区，在目录、批量运行、运行等按钮上方。
- 语言文字使用 `24px` 粗体等宽字体并在色块中水平、垂直居中。
- 色块采用 `12px` 圆角、轻微内高光和阴影，形成完整卡片效果，而不是紧凑徽标。
- 鼠标悬停时显示完整名称：`JavaScript 脚本` 或 `Python 脚本`。

## 实现方式

详情面板直接读取现有 `script.language` 字段，并复用 `scriptLanguageBadge()` 生成文案与颜色类。右侧操作区保持纵向布局：大语言卡靠右对齐，原有按钮保持同一行。语言卡通过详情面板局部 CSS 放大，共享 helper 仍负责语言文案和基础色彩。无需新增语言推断逻辑，也不改变脚本数据结构。

详情面板宽度低于 `620px` 时，整个操作区继续按现有容器查询规则移动到标题下方；大语言卡仍靠右显示，避免挤压脚本名称、分类和版本信息。

## 边界与兼容性

- `ScriptLanguage` 目前只允许 `javascript` 和 `python`，因此不设计未知语言占位状态。
- 徽标不提供点击行为，不影响原有头部按钮和拖拽缩放。
- 保持脚本卡片与详情面板语言标识的文案和配色一致。

## 验证

- 扩展详情头部回归测试，检查语言徽标使用共享 helper、读取 `script.language`，并包含 `JS` / `Py` 规则。
- 运行定向测试、完整单测、ESLint 和生产构建。
