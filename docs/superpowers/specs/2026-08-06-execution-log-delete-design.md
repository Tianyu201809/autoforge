# 运行日志与历史删除设计

## 背景

Autoforge 当前支持在终端面板按会话清空运行日志，也支持查看 SQLite 中的运行历史，但不支持删除单条日志或批量删除记录。日志由 `useScriptRunner` 在 renderer 内存中维护；运行历史由主进程 `ExecutionRepository` 持久化。

## 目标

1. 运行日志支持进入编辑模式后勾选多条并批量删除。
2. 运行日志支持右键删除单条记录。
3. 运行历史支持当前页勾选多条并批量删除。
4. 运行历史支持右键删除单条记录。
5. 日志和历史采用一致的编辑、选择、确认和反馈交互。

## 非目标

- 不改变日志的内存生命周期、2000 行上限或 MCP 日志读取语义。
- 不持久化历史日志行，也不增加日志恢复功能。
- 不提供跨分页的“筛选结果全选”；批量历史删除仅作用于当前已加载页。
- 不允许删除运行中的运行历史记录。
- 不新增软删除、回收站或恢复能力。

## 方案

采用最小改动的双通道实现：

- **运行日志**：继续由 `useScriptRunner` 保存内存日志。每条日志接收时补充稳定的 renderer `id`，删除只从当前内存集合移除，不影响运行器、session 状态、生命周期事件或后续新日志。
- **运行历史**：继续由 SQLite 保存。主进程新增按 ID 删除的 IPC，仓储提供单条删除和事务包裹的批量删除。
- **交互层**：日志列表和运行历史列表分别维护编辑模式及选中 ID，但复用相同的交互规则。

## 交互设计

### 普通模式

- 工具栏新增“删除/编辑”入口；点击后进入编辑模式。
- 单条记录右键打开操作菜单，选择“删除此条”后立即执行，不弹确认。

### 编辑模式

- 每条记录显示复选框。
- 工具栏显示“全选当前列表”“取消”“删除已选（N）”。
- 没有选中记录时，“删除已选”禁用。
- 批量删除弹出确认弹窗，文案包含实际条数；确认后执行删除。
- 删除成功后退出编辑模式、清空选中 ID，并显示实际删除数量；失败时保留编辑模式和选中状态并显示错误 Toast。

### 作用范围与运行中行为

- 日志删除仅作用于当前显示会话；多会话终端不会跨会话误删。
- 当前运行中的 session 可以删除已有日志行；后续产生的新日志仍继续显示。
- 运行历史批量删除仅作用于当前已加载页。
- 运行中的历史记录不允许删除；运行结束后记录仍可按普通历史记录删除。

## 数据与接口

### renderer 日志

- 扩展日志行类型或 renderer 内部包装类型，增加稳定 `id`。
- 列表 key、选中集合和删除操作均使用 `id`，不再使用 `时间戳 + 索引`。
- 删除接口接收单个 ID 或 ID 数组，并限制在当前显示集合内。

### 主进程运行历史

- 新增 IPC 方法：单条删除接收 `recordId`，批量删除接收 `recordId[]`。
- handler 校验 ID 类型和数组长度后调用 `ExecutionRepository`。
- repository 新增 `deleteById` 和 `deleteByIds`；批量删除使用事务，返回实际删除数量。
- 不存在的 ID 和重复 ID 不视为业务错误，结果按实际删除数量返回。

## 错误处理与安全

- 所有删除操作仅接受记录 ID，不接受拼接 SQL 的字段或条件。
- 删除失败不得清空本地选择状态；Toast 展示可读错误。
- 删除确认只在批量操作前出现，避免右键单条删除的额外交互成本。
- 运行历史删除不改变正在运行 session 的状态，也不影响执行完成回写；运行中记录在 UI 层禁用删除入口。

## 测试计划

### 主进程

- repository：单条删除、批量删除、事务回滚、空数组、重复 ID、不存在 ID。
- IPC handler：参数校验、返回实际删除数量、运行中记录拒绝删除。

### renderer

- runner：日志 ID 稳定生成、删除单条、删除多条、按 session 限制、运行中继续接收新日志。
- 组件：编辑模式切换、全选当前列表、取消选择、空选择禁用、批量确认、右键单条删除和成功/失败反馈。

### 验收标准

1. 日志工具栏可进入编辑模式，勾选并确认删除当前会话的多条日志。
2. 日志行右键删除立即生效，运行仍可继续输出。
3. 运行历史当前页可勾选并确认批量删除。
4. 运行历史单条右键删除立即生效，运行中记录不可删除。
5. 删除后列表、计数、选择状态和 Toast 与实际删除数量一致。

## 影响范围

- renderer：`useScriptRunner`、日志控制台组件、运行历史列表及其状态管理。
- preload/shared：日志 ID 类型和新增 runner/history IPC 类型。
- main：IPC handler、`ExecutionHistoryService`、`ExecutionRepository`。
- tests：上述主进程仓储、IPC 与 renderer 组件的相邻测试。
