# Hub Script Installation Progress

## Goal

在脚本中心安装脚本时，让发起安装的脚本卡片显示真实安装阶段与下载进度，不阻塞浏览其他脚本。

## Design

主进程在 Hub ZIP 安装流水线中发出结构化进度事件，事件包含 `hubScriptId`、阶段、阶段文案、百分比以及可选的已下载/总字节数。阶段依次为准备下载、下载脚本包、解压脚本包、校验脚本包、导入本地；下载阶段由响应 `content-length` 和实际流量计算百分比，未知总大小时使用不定进度状态。

IPC 将进度广播到渲染进程。脚本中心通过 `hubScriptId` 将事件绑定到对应卡片：安装中显示细进度条、阶段文案和字节数；完成由现有成功提示收尾；失败显示错误文案并允许再次安装。现有一次只允许一个安装任务的约束保持不变。

## Error Handling

下载、解压、校验或导入失败时，主进程先发送错误阶段事件，再抛出原有安装错误。渲染层保留失败状态直到用户重试或关闭脚本中心，避免错误只出现在短暂 Toast 中。

## Testing

- 单元测试验证下载流在有 `content-length` 和无 `content-length` 时均产生正确进度。
- 单元测试验证各安装阶段事件顺序及失败事件。
- 现有 Hub 安装、ZIP 安全和脚本中心测试继续通过。
