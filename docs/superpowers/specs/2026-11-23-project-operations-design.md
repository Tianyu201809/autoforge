# 项目工作区操作设计

**日期**：2026-11-23
**状态**：按用户请求实施
**范围**：Autoforge AI 项目工作区

## 意图

让用户能从项目列表管理项目名称、置顶顺序和对话导出，并通过两次确认移除项目记录。

## 方案

- 始终显示重命名、置顶、导出、删除等按钮会挤压窄侧栏中的项目名称。
- 右键菜单不易发现，触屏和键盘操作也较弱。
- 每个项目条目提供独立的“更多操作”按钮，打开明确的菜单。项目条目原有单击行为仍用于打开项目。

## 交互与数据

- 菜单提供“重命名”“置顶/取消置顶”“导出对话”“删除项目”。
- 删除需要连续完成两次独立确认。确认文字说明只删除 Autoforge 项目记录和对话，不删除本机项目文件夹。
- SQLite 为项目增加默认关闭的 pinned 状态。列表中置顶项优先显示，其余顺序沿用最近更新时间。
- 导出使用系统保存对话框，生成 UTF-8 JSON，包含版本、项目元数据和全部对话轮次。轮次保留状态、文件变更、检查结果和导入脚本关联。
- 重命名与置顶均由主进程验证项目 ID 并持久化。
- 已在运行 Agent 的项目不能删除，界面展示拒绝原因。

## 验收

- 单击项目条目仍打开对话。操作菜单可被鼠标和键盘触发。
- 重命名立即更新列表和活动项目标题，重启后保留。
- 置顶与取消置顶更新顺序且重启后保留。
- 导出取消时无副作用。确认保存后 JSON 包含完整项目和轮次字段。
- 删除流程显示两次确认。最终删除后列表和 SQLite 轮次均移除，本机目录仍在。
