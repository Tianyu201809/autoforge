# Autoforge v2.0.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver the approved v2.0 AI project agent and Codex-like unified Autoforge workbench.

**Architecture:** Implement model protocols and secure credentials first, then persistent local project/Agent services, then integrate both into a new main-window workbench while preserving the existing script library and execution services. All model requests and project file operations remain in the main process.

**Tech Stack:** Electron 34, Vue 3, TypeScript, sql.js, Electron `safeStorage` and `net.fetch`, Node `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-22-v2-agent-workspace-design.md`

**Detailed plans:**

- `docs/superpowers/plans/2026-11-22-v2-model-providers.md`
- `docs/superpowers/plans/2026-11-22-v2-project-workspace.md`
- `docs/superpowers/plans/2026-11-22-v2-workbench-ui.md`

## Execution Order

1. Complete `v2-model-providers` Tasks 1-5. This defines provider contracts and typed IPC consumed by Agent and settings UI.
2. Complete `v2-project-workspace` Tasks 1-6. This adds storage, safe project IO, checks, script association, Agent orchestration, and IPC.
3. Complete `v2-workbench-ui` Tasks 1-5. Keep the current runner/composables alive while routing existing views into the shell.
4. Run the full desktop unit suite, lint, build, and end-to-end manual workflow. Confirm existing Hub, MCP, script run, tray, editor, and terminal workflows.
5. Update `package.json` and lockfile to `2.0.0`, add `docs/v2.0.0.md`, update README/CHANGELOG/architecture links, and mark the implementation plan complete after verification.

## Release Acceptance

- OpenAI, Anthropic, Gemini, OpenAI-compatible DeepSeek/Qwen/GLM/Kimi presets and custom compatible endpoints pass protocol tests.
- API keys use `safeStorage` and never enter renderer responses, SQLite, logs, or errors.
- A selected empty folder can become a persistent project, survive app restart, and be removed from Autoforge without deleting the folder.
- Agent file tools stay inside the selected root, detect concurrent changes, and cannot execute arbitrary commands or generated scripts.
- Package validation and JS/Python syntax checks gate automatic import. Imported scripts are not automatically run.
- Rechecking a changed project updates its associated script while preserving its ID, preferences, and environment values; failed updates leave the prior imported script usable.
- The shared shell exposes all previously existing script management, execution, Hub, MCP, history, settings, guide, popout, shortcut, tray, and drag/drop workflows.
- `npm run test:unit`, `npm run lint`, and `npm run build` pass.
